Sample Work

Sample 01 · Response Evaluation

AI Answer Quality Review

Objective: Review a hypothetical AI answer to a user asking how to reset a forgotten password.

Evaluation criteria
  • Does the answer address the user's request?
  • Are steps ordered and easy to follow?
  • Does it avoid inventing platform-specific instructions?
  • Does it include appropriate account-security guidance?
Example feedback

“The response is easy to follow, but it should clarify that the reset process depends on the service. It should direct the user to the official recovery page and remind them not to share verification codes.”

Sample 02 · Prompt Engineering

Improving a Vague Prompt

Original prompt: “Write a good customer support reply.”

Revised prompt: “Write a professional, empathetic reply to a customer whose software login is failing. Acknowledge the inconvenience, provide three safe troubleshooting steps, avoid requesting passwords or verification codes, and ask for the exact error message if the issue continues. Keep the response under 120 words.”

Why this improves the prompt: It defines the situation, tone, required content, safety boundaries, and output length—making the result easier to evaluate consistently.
Sample 03 · Data Labelling

Text Classification Mini Exercise

Task: Categorise sample customer messages using a small, clearly defined label set.

Labels
  • Access: login, password, or account access
  • Billing: payment, invoice, or charges
  • Technical: errors, performance, or malfunction
  • Other: does not fit the above categories
Example annotation

Message: “I was charged twice for my subscription.”
Label: Billing
Reason: The message directly concerns a duplicate charge.

Quality check: use the same label definitions for every item and flag cases that genuinely fit more than one category.
